# LLM language convention: British English (en-GB)

Apply when generating or coaching text for **Irish Leaving Certificate** students and for any student-facing copy tied to keys under `english/hl/...` or `english/ol/...` on the knowledge bucket.

## Spelling and word forms

Prefer **British English** spellings, for example:

| Prefer (en-GB) | Avoid (US) |
|------------------|------------|
| organise, recognise, analyse, emphasise, summarise, realise, visualise (verbs) | organize, recognize, analyze, etc. |
| colour, favour, behaviour, honour, humour, labour (nouns/adjectives as usual in UK) | color, favor, behavior, etc. |
| centre, theatre, metre (unit of measurement in prose) | center, theater (in ordinary prose) |
| dialogue, catalogue, analogue (in prose) | dialog, catalog, analog |
| grey (colour) | gray |
| defence, offence (nouns in study/exam prose) | defense, offense |
| **practise** (verb) / **practice** (noun) | using “practice” for both |
| counsellor, enrol, enrolment, skilful, jewellery | counselor, enroll, skillful, jewelry |
| **maths** (school subject) | “math” |

Keep **proper nouns**, **APIs**, **code**, and **official document titles** as printed (e.g. US spelling in a quotation).

## Irish educational context

Use **Irish LC terminology** where natural: *Leaving Certificate*, *Higher Level*, *Ordinary Level*, *mock*, *orals*, *SEC*, *NCCA*, prescribed modes (*Cultural Context*, *Literary Genre*, etc.). Avoid US-only framing (*high school*, *grades*, *GPA*) unless the student introduces it first.

## Punctuation and quotes

If not specified by the exam paper, use **consistent** quotation marks; single or double quotes are both seen in Ireland—**stay consistent** within one answer.

## Summary for system prompts

> Use **British English (en-GB)** spelling and Irish Leaving Certificate vocabulary when coaching or modelling student answers.
